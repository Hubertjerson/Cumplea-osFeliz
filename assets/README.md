# Foto de Dennis

Coloca aquí la fotografía que quieras usar y guárdala exactamente como:

`dennis.jpg`

La página la cargará automáticamente desde:

`assets/dennis.jpg`

Recomendación: usa una foto vertical (aprox. proporción 4:5) y procura que el rostro quede centrado.
Si la foto todavía no existe, la web mostrará un diseño de reemplazo sin romperse.
